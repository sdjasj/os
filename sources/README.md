# 原始课程资料清单

来源：[操作系统原理（2026 春季学期）](https://jyywiki.cn/OS/2026/)，抓取日期 2026-07-22。`site_html/` 是服务器返回的渲染页面，`notes/` 是从页面中的课程正文提取出的 Markdown，便于全文搜索。课程图片保存在 `site_html/static/img/`、`img/` 以及少量 `notes/` 配图中，实验直接引用的两份 PDF 保存在 `manuals/`；交互演示、视频和普通站外链接没有镜像。渲染页仍保留少量线上站内相对路径，因此这是一份可检索的资料快照，不是完全自包含的网站镜像。

这些材料对应的扩写教程见[30 讲逐讲详解](../tutorial/lectures/README.md)；每章末尾都带有 PPT 内容覆盖表，可从教程反查到本目录的原始讲义。
