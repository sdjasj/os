# 04 · 网络安全导论（Intro to Cybersecurity）

这一阶段把前面的 Linux、程序交互和底层计算知识组合成一套安全分析方法。重点不是记住某个关卡的输入，而是反复回答四个问题：系统信任什么、外部数据如何流动、哪条安全不变量可能失效、修复应当落在哪一层。

本目录参考 [pwn.college Intro to Cybersecurity](https://pwn.college/intro-to-cybersecurity/) 的模块顺序，所有讲解、代码、玩具数据与纸面练习均为独立原创。示例只处理内存数据、临时文件或 `127.0.0.1` 上的本地服务，不包含站内题面、flag、精确利用输入或逐关解答。

## 学完后能够

- 从解析、数据流和信任边界解释常见 Web 漏洞，而不是只背漏洞名称；
- 用分层模型理解 Ethernet、IP、TCP 与应用协议，并说明“能看到流量”不等于“能可信地修改流量”；
- 区分编码、哈希、MAC、加密、签名和密钥交换解决的问题；
- 用主体、客体、动作和策略描述 DAC、MAC、RBAC 与 ABAC；
- 结合静态与动态证据，从机器码中恢复控制流和数据流；
- 从内存错误推导读取、写入或控制流能力，并理解常见缓解机制的边界；
- 在综合系统中画出跨层攻击路径，再用纵深防御逐段切断。

## 建议阅读方式

每篇都采用同一条推理链：

```text
资产与目标
  -> 信任边界
  -> 输入经过哪些解释器或组件
  -> 应保持什么不变量
  -> 失效后得到哪种最小能力
  -> 哪项防御能在根因处切断路径
  -> 如何用测试验证修复
```

代码的“预期输出”用于帮助不方便动手的读者在纸面上追踪状态变化。若实际运行，请使用普通用户权限、临时目录和本机回环地址；不要把故意脆弱的示例部署到公网，也不要用它测试没有明确授权的系统。
