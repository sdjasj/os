# DeepSpeed 源码学习教程

这套教程基于 DeepSpeed 提交 `32e301ffaf5a7b2ae74be7a25b22c917bb4bf05a` 独立编写。目标不是罗列配置项，而是用仓库中的真实入口、运行时实现和测试，建立一套能解释“训练为什么能跑、显存为什么省下来、通信发生在哪里、出错时应查哪一层”的心智模型。

教程只引用上游源码，不复制项目源代码、模型、数据集、checkpoint、日志或构建产物。`UPSTREAM_LICENSE` 原样保留上游 Apache License 2.0，仅用于说明源码归属，不重新授权本教程。

## 四条学习轨道

| 轨道 | 文件 | 核心问题 |
| --- | ---: | --- |
| 基础与训练运行时 | `foundations/00` 至 `04` | DeepSpeed 包装了 PyTorch 的哪些部分？一次训练 step 怎样贯通配置、前向、反向与更新？ |
| ZeRO 与内存系统 | `zero/05` 至 `10` | 状态为何占显存？不同 ZeRO stage 分片什么？通信、生命周期与 offload 如何配合？ |
| 组合并行与推理 | `parallel/11` 至 `15` | Pipeline、TP、SP、MoE、checkpoint 和推理怎样与核心 Engine 组合？ |
| 工程化 | `engineering/16` 至 `19` | 多机任务怎样启动？算子怎样构建？分布式测试、性能排障和编译扩展怎样落地？ |

## 推荐顺序

第一次接触分布式训练时，按 `00 → 01 → 03 → 04 → 06 → 07 → 08 → 09` 学习。已经使用过 Hugging Face + DeepSpeed、但想读懂源码时，可以从 `03` 开始沿调用链阅读。准备改 DeepSpeed 本身时，还应完成 `02`、`17`、`18` 和 `19`。

每章都有以下固定构件：

1. 必要的背景知识和术语；
2. 当前提交中的关键源码入口；
3. 从输入到输出的调用链或状态变化；
4. 可在静态、单卡或多卡环境完成的实验；
5. 自测题与常见误区。

## 使用约定

文中的 `<project-root>` 指 DeepSpeed 仓库根目录。命令默认从该目录执行；带 GPU、多进程或 NVMe 的实验都明确标注前提。先做静态实验，再逐步增加硬件和进程数，能把“代码问题”和“环境问题”分开。

源码链接固定到教程所依据的提交。以后上游目录或 API 发生变化时，应先比较提交差异，再迁移结论，不要把本教程当成所有版本都不变的接口规范。
