## 从一个状态退化出的决策问题

### 动作与随机奖励

双臂老虎机每一步都回到同一个决策情境。动作集合为

\[
\mathcal A=\{0,1\},
\]

其中动作 0 对应 A，动作 1 对应 B。环境为每个动作给出伯努利奖励：

\[
R_t\mid A_t=a\sim \operatorname{Bernoulli}(p_a).
\]

\(t\) 是决策步，\(A_t\) 是本步动作，\(R_t\in\{0,1\}\) 是奖励，\(p_a\) 是动作 \(a\) 获得奖励 1 的真实概率。伯努利变量的期望就是其成功概率，所以真实动作价值为

\[
q_*(a)=\mathbb E[R_t\mid A_t=a]=p_a.
\]

脚本把 \(p_0\) 和 \(p_1\) 分别设为 0.6 与 0.4：

```python
class TwoArmedBandit:
    def __init__(self, prob_a=0.6, prob_b=0.4):
        self.prob_a = prob_a
        self.prob_b = prob_b
        self.best_prob = max(prob_a, prob_b)
```

`pull(arm)` 每次都重新调用 `np.random.random()`。即使连续选择同一拉杆，也可能得到 `1, 0, 0, 1`。一次奖励不能代表动作价值；学习对象是长期平均值。

### 随机策略给出可校验的基线

若两个动作都以 \(1/2\) 的概率选择，每步期望奖励为

\[
\tfrac12\times0.6+\tfrac12\times0.4=0.5.
\]

这给出第一个调试基线。运行足够多步、再平均足够多次后，`strategy_random` 的累计平均奖励应接近 0.5。若结果长期接近 0.6，动作采样可能偏向 A；若长期接近 0 或 1，奖励生成或平均方式可能有误。

## 用样本估计未知价值

### 样本均值

智能体看不到 `prob_a` 和 `prob_b`，只能记录每个动作得到的奖励。动作 \(a\) 被选择 \(N_t(a)\) 次后，其估计值是

\[
Q_t(a)=\frac{1}{N_t(a)}\sum_{i=1}^{N_t(a)}R_i^{(a)}.
\]

\(Q_t(a)\) 是第 \(t\) 步时的估计，\(N_t(a)\) 是动作计数，\(R_i^{(a)}\) 是第 \(i\) 次选择动作 \(a\) 时得到的奖励。大数定律说明，在平稳环境中，样本增多后 \(Q_t(a)\) 会接近 \(q_*(a)\)。

直接保存全部奖励会让内存随步数增长。脚本使用增量式均值：

```python
counts[arm] += 1
Q[arm] += (reward - Q[arm]) / counts[arm]
```

令旧计数为 \(n-1\)、旧均值为 \(Q_{n-1}\)、新奖励为 \(R_n\)，则

\[
Q_n=Q_{n-1}+\frac{1}{n}(R_n-Q_{n-1}).
\]

\(R_n-Q_{n-1}\) 是新观察相对旧估计的误差，\(1/n\) 是随样本数减小的步长。这个“旧估计加步长乘误差”的结构会在 Q-Learning、DQN 和策略梯度中反复出现。

### 一个三次拉杆的数值推演

假设 A 的前三次奖励为 `1, 0, 1`：

| 新计数 \(n\) | 新奖励 \(R_n\) | 更新前 \(Q\) | 更新后 \(Q\) |
| ---: | ---: | ---: | ---: |
| 1 | 1 | 0 | \(0+(1-0)/1=1\) |
| 2 | 0 | 1 | \(1+(0-1)/2=0.5\) |
| 3 | 1 | 0.5 | \(0.5+(1-0.5)/3=2/3\) |

最终结果 \(2/3\) 与直接计算 `(1 + 0 + 1) / 3` 相同。`Q` 和 `counts` 都是形状 `(2,)` 的 NumPy 数组，索引就是动作编号。

## 四种选择策略

### 随机：只探索的对照组

`strategy_random` 用 `np.random.choice([0, 1])` 等概率选动作，也不维护 `Q`。它能持续发现两个动作，却不会利用已经得到的证据。其长期奖励约为 0.5，适合作为最低限度的学习对照。

### 贪心：早期噪声会被后续决策放大

贪心策略选择

\[
A_t=\arg\max_a Q_t(a).
\]

它把全部决策机会交给当前估计最大的动作。真实代码先执行 `Q = np.zeros(2)`，随后调用 `np.argmax(Q)`。NumPy 在最大值并列时返回第一个索引，因此第一步固定选择动作 0，并非源码注释所说的“随机选一个拉杆”。这是阅读实验代码时很重要的实现细节。

固定偏向动作 0 在当前参数下恰好偏向真实更优的 A，会让纯贪心看起来比一般情形更强。把构造函数参数交换为 `prob_a=0.4, prob_b=0.6`，这个平局规则就会暴露风险：B 没有被尝试时，其估计一直是 0，早期结果可能让策略长时间停在 A。

若要让平局随机，可先找到所有最大值索引，再从中抽样：

```python
best = np.flatnonzero(Q == Q.max())
arm = np.random.choice(best)
```

这段代码用于实验改造，原脚本并未采用它。比较结果时应明确记录是否改变了平局规则。

### ε-贪心：给探索保留固定概率

ε-贪心在每一步做一次概率分支：

\[
A_t=\begin{cases}
\text{从两个动作中均匀采样}, & \text{概率 }\varepsilon,\\
\arg\max_a Q_t(a), & \text{概率 }1-\varepsilon.
\end{cases}
\]

脚本默认 `epsilon=0.1`。若当前贪心动作是 A，那么选择 A 的总概率是

\[
(1-0.1)+0.1\times\tfrac12=0.95,
\]

选择 B 的概率是 0.05。这里“10% 探索”不等于“10% 选择非贪心动作”，因为随机探索也可能再次选中贪心动作。

固定 ε 会永久保留少量试错。它适合参数可能变化的环境，也会在当前平稳问题中产生线性增长的探索代价。若要逐步转向利用，可以令 \(\varepsilon_t\) 随时间下降，但下降过快仍可能锁定错误估计。

### UCB：让不确定性决定探索对象

上置信界策略选择

\[
A_t=\arg\max_a\left[Q_t(a)+c\sqrt{\frac{\ln t}{N_t(a)}}\right].
\]

公式中，\(Q_t(a)\) 是经验均值，\(N_t(a)\) 是选择次数，\(t\) 是总步数，\(\ln t\) 让探索压力随时间缓慢增长，\(c\ge 0\) 控制不确定性奖励的强度。括号中的第二项在动作样本少时较大，随着该动作被反复选择而缩小。

脚本先在 `t <= 2` 时依次选择动作 0 和 1，因此进入公式时两个 `counts[a]` 都大于零，避免除零。随后构造形状 `(2,)` 的 `ucb_values` 并取 `argmax`。

考虑 \(t=100\)、`Q=[0.58, 0.45]`、`counts=[80, 20]`、\(c=2\)：

\[
UCB(A)\approx0.58+2\sqrt{4.605/80}=1.060,
\]

\[
UCB(B)\approx0.45+2\sqrt{4.605/20}=1.410.
\]

B 的均值较低，但样本更少，因此本步会探索 B。`c=0` 会退化为先各试一次后的贪心；更大的 `c` 会延长探索阶段。

## 怎样读两张结果图

### 累计平均奖励

脚本先把 200 次运行在每个时间点的奖励相加，再除以 `n_runs`，得到 `all_rewards[name][t]`。随后计算

\[
\bar R_t=\frac{1}{t}\sum_{i=1}^{t}\widehat{\mathbb E}[R_i].
\]

\(\widehat{\mathbb E}[R_i]\) 是 200 次运行在第 \(i\) 步的平均奖励。随机曲线应在 0.5 附近，能稳定识别 A 的策略会向 0.6 靠近。有限样本下曲线会波动，不应要求某次运行严格保持排序。

### 累计遗憾

最优固定策略每步的期望奖励为 `best_prob = 0.6`。脚本按

\[
\widehat{L}_T=\sum_{t=1}^{T}\left(0.6-\widehat{\mathbb E}[R_t]\right)
\]

绘图，并在汇总表中用 `0.6 * n_steps - total_reward` 得到同一量。它利用跨运行平均奖励估计期望累计遗憾。单次真实奖励可以是 1，所以单步的 `0.6 - reward` 可能为负；重复平均后，曲线才接近期望意义下的比较。

还可以直接按动作计算伪遗憾：选择 A 的代价为 0，选择 B 的期望代价为 \(0.6-0.4=0.2\)。这种写法隔离了奖励噪声，但需要额外记录每一步动作。原脚本没有保存动作历史。

## 参数实验：一次只回答一个问题

### 实验一：交换最优动作

把 `run_experiment` 中的环境改成 `TwoArmedBandit(prob_a=0.4, prob_b=0.6)`，同时把绘图用的 `best_prob` 改为 0.6。保持其余参数不变。

预期观察：随机基线仍约为 0.5；纯贪心更容易受索引 0 的初始偏置影响；ε-贪心和 UCB 有机会发现动作 1。这个实验检验算法是否依赖恰好有利的数组顺序。

### 实验二：扫描 ε

分别使用 `epsilon` 为 0、0.01、0.1、0.3，记录最终累计平均奖励与总遗憾。建议固定一组种子：

```python
for seed in range(20):
    np.random.seed(seed)
    # 运行同一组参数并保存指标
```

预期观察：ε 为 0 时结果对早期样本最敏感；ε 较大时更快纠正错误判断，同时长期仍会频繁选择较差动作。哪个值更好取决于总步数，不能脱离 `n_steps` 单独下结论。

### 实验三：扫描 UCB 的 c

比较 `c=0, 0.5, 1, 2, 4`。同时统计 `counts`，观察每个动作实际被选多少次。

预期观察：`c=0` 接近贪心；`c` 增大后，B 的选择次数通常上升。默认 `c=2` 是教学参数，并非所有奖励尺度与时域上的通用最优值。

### 实验四：让环境发生变化

在第 500 步交换 A、B 的获奖概率。样本均值为早期全部历史赋予同等权重，适应会很慢。可以把更新改为常数步长

\[
Q_{t+1}(a)=Q_t(a)+\alpha(R_t-Q_t(a)),
\]

例如 \(\alpha=0.1\)。近期样本因此拥有更大影响。这个改造说明：估计器必须匹配环境是否平稳。

## 公平实验需要控制什么

原脚本运行 200 次并平均，已经比只画一条轨迹可靠，但没有显式设置随机种子，也没有画标准差或置信区间。四种策略还依次消耗同一个 NumPy 全局随机流；它们面对的是相同参数分布，却没有逐步共享完全相同的潜在随机结果。

严谨比较可以遵循以下顺序：

1. 预先列出多组种子，每个策略都使用同一组种子集合；
2. 每个“策略 × 种子”创建独立环境和随机数生成器；
3. 同时报告均值、标准差或置信区间；
4. 保持 `n_steps`、奖励概率、平局处理和评价指标一致；
5. 在另一组未用于调参的种子上确认结论。

不要从一次曲线交叉推出算法优劣。老虎机奖励本身有方差，参数差异也可能只改变前期速度。

## 代码的教学简化与边界

这个实验刻意保持小型，因此结论有清楚的适用范围：

- 环境只有一个状态，动作不会改变下一步情境；
- 两个动作的奖励独立且默认平稳；
- 奖励只有 0 和 1，UCB 参数与该尺度绑定；
- 贪心与 ε-贪心的并列最大值固定偏向索引 0；
- 没有上下文信息、延迟奖励、动作成本和安全约束；
- 图中的“最终平均奖励”字段实际打印 `rewards[-1]`，表示最后一个时间点跨运行的平均奖励，方差通常高于累计平均值；
- 结果图适合建立直觉，算法比较仍需多种子统计。

有了状态和状态转移，同一个动作在不同位置会产生不同后果，单个长度为 2 的 `Q` 就不够用了。下一章会把动作价值扩展成 `Q[state][action]`，并用贝尔曼关系传播未来奖励。

## 自测

### 题目

1. 当前贪心动作是 A、ε 为 0.2 时，ε-贪心选择 B 的概率是多少？
2. 某动作旧估计为 0.5，更新前已选择 4 次，新奖励为 1。更新后的样本均值是多少？
3. UCB 为什么要先让每个动作至少执行一次？
4. 将 A、B 概率都改为 0.5 后，长期伪遗憾应怎样变化？
5. 为什么 200 次运行的平均曲线仍不足以证明 UCB 在所有老虎机问题上更好？

### 参考答案

1. 探索分支概率为 0.2，其中一半选择 B，所以是 0.1。
2. 新计数为 5，结果是 \(0.5+(1-0.5)/5=0.6\)。
3. 公式含有 \(1/N_t(a)\)；零计数会造成除零，同时也意味着该动作没有任何价值估计。
4. 两个动作期望相同，每次选择相对最优动作的期望差都是 0，所以伪遗憾为 0；实际奖励曲线仍会随机波动。
5. 当前实验只有两个平稳伯努利动作、固定时域和一组参数，也没有跨问题分布或置信区间。结论只能描述这组设置下的估计表现。
