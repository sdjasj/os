# 03. 从 GridWorld 推导 MDP、贝尔曼方程与 Q-Learning

双臂老虎机的每次选择都发生在同一个情境中。进入网格世界后，动作会改变位置，当前位置又决定下一步可走的方向与奖励。学习对象因此从两个动作的平均奖励，扩展为“每个状态下每个动作的长期价值”。

本章以 [`gridworld_q_learning.py`](./gridworld_q_learning.py) 为主线，并把其中的数组操作还原成马尔可夫决策过程、贝尔曼最优方程和时序差分更新。你会看到一个形状为 `(4, 4, 4)` 的 Q 表怎样逐步形成最短安全路径。

## 先把环境读成一张状态图

### 状态、动作与奖励

`GridWorld` 使用 4 行 4 列的位置作为状态：

```text
S  ·  ·  ·
·  X  ·  ·
·  ·  X  ·
·  ·  ·  G
```

`S=(0,0)` 是起点，`G=(3,3)` 是终点，`X` 是 `(1,1)` 和 `(2,2)` 两个障碍。状态用二元组 `(row, col)` 表示。动作编号固定为：

| 编号 | 动作 | 坐标变化 |
| ---: | --- | --- |
| 0 | 上 | `row - 1` |
| 1 | 下 | `row + 1` |
| 2 | 左 | `col - 1` |
| 3 | 右 | `col + 1` |

普通合法移动奖励为 -1，到达终点奖励为 +10；撞墙或撞障碍后位置不变，奖励为 -5，回合继续。负的步进奖励会让绕路的回报更低，于是“尽快到达”被编码进优化目标。

环境的 `step` 返回三元组：

```python
next_state, reward, done = env.step(action)
```

只有到达 `(3,3)` 时 `done=True`。障碍是带惩罚的非法移动，并非终止状态。

### 马尔可夫性质

一个状态若已经包含预测未来所需的信息，就满足马尔可夫性质：

\[
P(S_{t+1},R_{t+1}\mid S_t,A_t,S_{t-1},\ldots)
=P(S_{t+1},R_{t+1}\mid S_t,A_t).
\]

这里知道当前位置和动作就足以确定下一位置及奖励，过去走过哪条路不会改变 `step` 的结果。当前 GridWorld 还是确定性环境：给定 \((s,a)\) 后，下一状态和奖励唯一。MDP 形式也允许它们服从概率分布。

### MDP 五元组

这个任务可以写成

\[
(\mathcal S,\mathcal A,P,R,\gamma).
\]

- \(\mathcal S\) 是 16 个网格坐标；障碍坐标存在于数组中，但正常转移不会进入它们；
- \(\mathcal A=\{0,1,2,3\}\)；
- \(P(s'\mid s,a)\) 描述转移，当前实现的概率为 0 或 1；
- \(R(s,a,s')\) 给出 -5、-1 或 +10；
- \(\gamma=0.95\) 是默认折扣因子。

有了状态转移，某一步的好坏取决于它通向哪里。只比较即时奖励会看不到“先付出 -1，几步后得到 +10”的价值，因此需要回报。

## 从即时奖励到长期回报

### 折扣回报

从时间 \(t\) 开始的回报定义为

\[
G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots.
\]

\(R_{t+1}\) 是执行 \(A_t\) 后得到的即时奖励，\(\gamma\in[0,1]\) 控制较远奖励的权重。\(\gamma=0\) 只看下一步；\(\gamma\) 接近 1 时，远期奖励保留更多影响。

假设从某位置还需三步到终点，奖励序列是 `[-1, -1, 10]`。当 \(\gamma=0.95\) 时：

\[
G_t=-1+0.95(-1)+0.95^2(10)=7.075.
\]

若绕路后奖励为 `[-1, -1, -1, 10]`，回报变为

\[
-1-0.95-0.95^2+0.95^3(10)=5.72125.
\]

终点奖励相同，额外一步的惩罚和折扣共同降低了绕路价值。

### 策略、状态价值与动作价值

策略 \(\pi(a\mid s)\) 描述在状态 \(s\) 选择动作 \(a\) 的概率。给定策略后，状态价值为

\[
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s],
\]

动作价值为

\[
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
\]

\(V^\pi(s)\) 评价“到达这个位置后按策略行动”，\(Q^\pi(s,a)\) 还固定了第一步动作。知道所有 \(Q^\pi(s,a)\) 后，可以直接比较同一状态的四个动作。

Q-Learning 要逼近的是最优动作价值

\[
Q_*(s,a)=\max_\pi Q^\pi(s,a).
\]

它表示先在 \(s\) 执行 \(a\)，此后一直采取最优行为时的期望回报。

## 贝尔曼关系为什么能传播终点奖励

### 一步递归

回报可以拆成一步奖励与剩余回报：

\[
G_t=R_{t+1}+\gamma G_{t+1}.
\]

把这条递归放入最优动作价值，就得到贝尔曼最优方程：

\[
Q_*(s,a)=\mathbb E\left[R_{t+1}+\gamma\max_{a'}Q_*(S_{t+1},a')\mid S_t=s,A_t=a\right].
\]

\(s,a\) 是当前状态与动作，\(S_{t+1}\) 是随机下一状态，\(a'\) 枚举下一状态可选动作，\(\max_{a'}\) 表示从下一步开始采用最优选择，期望覆盖环境的随机转移与奖励。

当前 GridWorld 是确定性的，因此一次转移就会给出一个具体的 \(s'\) 和 \(r\)。仍然未知的部分是 \(Q_*\)，算法通过反复采样和自举逐渐逼近它。

若想先用已知小型 MDP 检查贝尔曼等式，可以运行同目录的 [`bellman_equation_verify.py`](./bellman_equation_verify.py)：

```bash
python chapter03_mdp/bellman_equation_verify.py
```

### 自举的含义

目标

\[
r+\gamma\max_{a'}Q(s',a')
\]

包含当前估计出的下一状态价值。算法用一个估计去更新另一个估计，这叫自举。终点附近先接触 +10 的状态—动作对，随后这些较高 Q 值逐步成为前一个状态的目标，于是终点信息向起点传播。

## 把公式逐行对应到 Q-Learning

### Q 表的形状与索引

初始化代码为：

```python
Q = np.zeros((env.rows, env.cols, env.n_actions))
```

在本环境中，`Q.shape == (4, 4, 4)`。第一维是行，第二维是列，第三维是动作。若 `state=(2,1)`，则 `Q[state]` 等价于 `Q[2,1]`，形状是 `(4,)`；`Q[state][3]` 是在 `(2,1)` 向右的标量价值。

总共只有 \(4\times4\times4=64\) 个槽位，所以表格方法可行。障碍状态和终点的某些槽位不会被正常训练到，仍可能保持初始值 0。

### 行为策略仍然需要探索

`epsilon_greedy` 以 ε 概率调用 `np.random.randint(n_actions)`，否则返回 `np.argmax(Q[state])`。开始时 ε 为 1，动作完全随机；每个回合结束后执行：

```python
epsilon = max(epsilon_end, epsilon * epsilon_decay)
```

默认衰减为 0.995。第 500 回合结束后的理论值约为

\[
1.0\times0.995^{500}\approx0.0816,
\]

仍高于下限 0.01。因此这次默认训练不会真正衰减到 `epsilon_end`。这个计算有助于避免只看参数名就误以为最后几乎没有探索。

`np.argmax` 在并列时返回最小索引。初始利用分支会偏向动作 0“向上”，而起点向上会撞墙。高初始 ε 会很快收集其他动作的数据，减轻这个偏置，但多种子比较仍应明确它的存在。

### 时序差分目标与误差

核心实现是：

```python
best_next_q = np.max(Q[next_state])
td_target = reward + gamma * best_next_q
td_error = td_target - Q[state][action]
Q[state][action] += alpha * td_error
```

对应更新式：

\[
Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right].
\]

\(\alpha\in(0,1]\) 是学习率，控制本次误差写入多少；方括号是时序差分误差，简称 TD 误差。\(\alpha=1\) 会把旧值直接替换为当前目标，\(\alpha\) 较小会平滑多次观察。

### 一次更新的数值推演

设当前 `Q[state][action] = 2.0`，执行后奖励 `reward = -1`，下一状态四个动作值为 `[1.2, 4.0, 2.5, 3.1]`，默认 `gamma=0.95`、`alpha=0.1`。

先取下一状态最大值：

\[
\max_{a'}Q(s',a')=4.0.
\]

再计算目标与误差：

\[
y=-1+0.95\times4.0=2.8,
\]

\[
\delta=2.8-2.0=0.8.
\]

最终更新为

\[
Q(s,a)\leftarrow2.0+0.1\times0.8=2.08.
\]

这一步没有等待整个回合结束，只用了相邻两个状态，因此 Q-Learning 属于一步时序差分方法。

### 为什么说它是离策略学习

收集数据的行为策略是带探索的 ε-贪心策略，更新目标却使用 \(\max_{a'}Q(s',a')\)，假设下一步选择当前最优动作。产生样本的策略与被评价的目标策略不同，所以它是离策略算法。

若目标使用行为策略实际在 \(s'\) 选择的下一动作 \(a'\)，形式会变为 SARSA：

\[
Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma Q(s',a')-Q(s,a)].
\]

本脚本没有实现 SARSA，这个对照只用于理解 `np.max` 的含义。

## 终止转移需要单独处理

稳健的 Q-Learning 目标应写成

\[
y=r+\gamma(1-d)\max_{a'}Q(s',a'),
\]

其中 \(d=1\) 表示这次转移到达终止状态。终止后没有下一动作，因此自举项必须清零。

当前代码无论 `done` 是否为真都计算 `reward + gamma * best_next_q`。在这个特定实现里，到达终点后不再从终点执行动作，终点对应的 Q 向量保持初始零值，所以目标数值仍是 \(10+0.95\times0=10\)。这个结果依赖“终点 Q 值永远为零”的隐含条件。环境或初始化一旦变化，就应显式写成：

```python
best_next_q = 0.0 if done else np.max(Q[next_state])
td_target = reward + gamma * best_next_q
```

这也是下一章 DQN 中 `(1 - dones)` 掩码的来源。

## 一次训练循环怎样形成路径

每个回合从 `env.reset()` 回到 `(0,0)`，反复选择动作、转移、更新 Q 表，直到到达终点。`steps > 200` 是安全阀；若策略没有到达终点，循环会在步数增至 201 后退出，这种退出没有单独记录为终止类型。

训练 500 回合后，脚本用每个状态的 `np.argmax(Q[state])` 打印最佳动作，并从起点贪心提取路径。理想路径会避开两个障碍，并用 6 次合法移动到达 `(3,3)`。由于上→下或右→下等多条最短路径可能同值，具体箭头序列会受采样噪声和平局规则影响。

训练日志每 100 回合报告最近 100 回合平均奖励与平均步数。早期高 ε 会造成撞墙、撞障碍和绕路；学习推进后，平均奖励通常上升、平均步数下降。一次随机运行未必单调，判断趋势应看滑动区间与多个种子。

## 参数实验

### 实验一：学习率 α

比较 `alpha=0.01, 0.1, 0.5, 1.0`，保持随机种子和其余参数相同。

预期观察：小 α 更新缓慢；大 α 很快响应最近目标，也更容易受样本顺序影响。当前环境确定且奖励固定，大 α 可能表现很好，这不能直接推广到随机环境。

### 实验二：折扣因子 γ

比较 `gamma=0, 0.5, 0.95, 1.0`。当 γ 为 0 时，只看即时奖励；普通移动都是 -1，终点奖励无法跨多步充分传播。γ 增大后，远处的 +10 会影响更多前驱状态。

记录 `(0,0)` 的四个 Q 值，而不只看最终路径。这样能直接观察长期价值是否传到起点。

### 实验三：探索衰减

比较 `epsilon_decay=0.9, 0.99, 0.995, 1.0`。先计算每个设置在第 100 和第 500 回合的 ε，再解释结果。

衰减太快时，早期偶然 Q 值可能固定后续数据分布；不衰减时，训练末期仍频繁撞墙。评价阶段应固定 ε 为 0，避免把探索代价混入策略质量。

### 实验四：随机转移

把 `step` 改成以 0.8 概率执行所选方向、以 0.2 概率执行一个随机方向。此时同一 \((s,a)\) 可产生不同 \(s'\)，Q 表需要通过重复样本估计期望。

预期观察：曲线方差增大，需要更多回合和多种子统计；终止掩码仍然必须按实际转移结果处理。

### 推荐的可复现设置

当前脚本没有设种子。实验入口可以先加入：

```python
seed = 7
np.random.seed(seed)
env = GridWorld()
```

正式比较应遍历多组种子，分别保存最终 100 回合平均奖励、步数和成功率，再报告均值与区间。固定一个种子只保证复现一条轨迹，不等于统计可靠。

## 教学实现的边界

- 状态直接用完整坐标表示，智能体没有感知误差；
- 转移默认确定，奖励函数固定且完全平稳；
- Q 表只适合小型离散状态与离散动作；
- 障碍坐标仍占用 Q 表槽位，但正常轨迹不会进入；
- 终止目标依靠终点 Q 值为零，缺少显式 `done` 掩码；
- `np.argmax` 的平局偏向动作 0；
- 训练安全阀与真正终止没有分开统计；
- 没有独立评价回合、多种子置信区间或策略成功率。

当状态从 16 个格子变成 CartPole 的连续位置、速度和角度时，无法为每个可能状态开一个表。下一章会保留同一个贝尔曼目标，用神经网络 \(Q_\theta(s,a)\) 代替表格，并加入经验回放和目标网络来控制训练不稳定性。

## 自测

### 题目

1. `Q[2, 1]` 与 `Q[2, 1, 3]` 的形状和含义分别是什么？
2. 当前 Q 值为 1，奖励为 -1，下一状态最大 Q 值为 3，\(\gamma=0.9\)、\(\alpha=0.2\)。更新后是多少？
3. 到达终点时，为什么通用公式要乘 `(1 - done)`？
4. Q-Learning 的行为策略和目标策略分别是什么？
5. 默认 500 回合后 ε 为什么没有到达 0.01？
6. 普通步奖励从 -1 改为 0，会怎样改变最短路径偏好？

### 参考答案

1. `Q[2,1]` 是形状 `(4,)` 的四动作价值向量；`Q[2,1,3]` 是在状态 `(2,1)` 向右的标量价值。
2. 目标为 \(-1+0.9\times3=1.7\)，误差为 0.7，更新后为 \(1+0.2\times0.7=1.14\)。
3. 终止后不存在下一动作与未来回报；保留自举项会把虚构的终点价值加进目标。
4. 行为策略是 ε-贪心，目标使用下一状态的最大 Q 值，对应贪心策略。
5. \(0.995^{500}\approx0.0816\)，仍高于下限，`max` 不会选到 0.01。
6. 只要最终都得到 +10，多个不同长度的无障碍路径可能拥有相同或更接近的回报；折扣仍可偏好较早到达，但步进奖励提供的直接长度压力消失。
